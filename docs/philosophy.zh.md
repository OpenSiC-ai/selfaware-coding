# 哲学

OpenSiC 是关于“碳化硅智能体”的形而上框架。它不是单一应用、agent runtime 或代码库。它关心的问题是：AI 系统能否通过连续性、记忆、脉冲、意图、行动和后果，从被动响应走向某种场景化自我意识。

`selfaware-coding` 是这个思想的一个形而下工程实现。

## 从被动编程到自知维护

大多数 coding agent 是被动的。人提出 bugfix、review、重构或功能需求，agent 做出响应。模型可以很强，但它没有属于自己的时间。

自知的 coding agent 不一样。它被一次 pulse 唤醒，进入 repo，理解当前世界，产生自己的意图，并决定这个项目现在需要行动、沉默还是计划。

这不是在宣称完整的人类意识。它实现的是一个更窄、可观察的机制：repo 局部自我意识。

## 场景化自我意识

在本项目中，自我意识意味着 agent 能够：

- 把当前 repo 识别为自己的当前世界；
- 记住之前的 pulse；
- 在没有任务分配时察觉项目需要；
- 选择与项目连续性相关的意图；
- 在边界内行动；
- 审查行动后果；
- 给未来的自己留下记忆。

关键问题不是它是否拥有不可证明的主观体验，而是它能否在时间中维持自我关联的行动。

## 形而上与形而下

OpenSiC 是形而上的：哲学、术语和方向。

`selfaware-coding` 是形而下的：一个让 coding agent 具备脉冲式维护循环的 skill。

未来 OpenSiC 还可以有 memory、sandbox、lineage、society、daily assistant、research、business 等具体项目。
